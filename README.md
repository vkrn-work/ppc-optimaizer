# PPC Optimizer

Система автоматизации управления поисковыми рекламными кампаниями в Яндекс Директ для B2B-компании в нише импортного металлопроката.

**Версия:** 1.3.0 · **Деплой:** Railway · **Статус:** Уровень 1 (аналитика) — в проде. Уровни 2–3 (CRM, ИИ-анализ, запись в Директ) — код готов, ждёт проверки на реальном кабинете и ключах.

## Что делает система

**Уровень 1 — сбор и аналитика (работает в проде)**
- Собирает данные из Яндекс Директ API v5 и Яндекс Метрики ежедневно (06:00 МСК)
- Анализирует динамику показателей: позиции, CTR, клики, расход (rule-based движок `cr_analyzer.py`)
- Трекает каждое изменение 7 дней и выдаёт вердикт: подтверждена / отклонена / нет данных
- Поддерживает несколько кабинетов одновременно

**Уровни 2–3 — CRM, ИИ-анализ, запись в кабинет (реализовано, не обкатано на боевых данных)**
- Импорт выгрузки заявок из CRM (CSV/XLSX — 1С, amoCRM, Bitrix24 и т.п.), матчинг по ключевому слову
- ИИ-анализ через выбор одного из 4 LLM-провайдеров: **Claude, Gemini, Groq, OpenRouter**
  (Gemini/Groq/OpenRouter — бесплатные варианты для теста без карты, Claude — платный)
- Генерация предложений по оптимизации с приоритетами (Сегодня / Неделя / Месяц) и safety-лимитами
  (макс. % изменения ставки, потолок ставки, дедупликация)
- Approve/reject предложений и запись подтверждённых изменений напрямую в Яндекс Директ
  (ставки, минус-слова, пауза/возобновление ключей, тексты объявлений)

> Код уровней 2–3 не был прогнан с реальными API-ключами и на реальном кабинете —
> см. предупреждение в [RAILWAY_DEPLOY.md](RAILWAY_DEPLOY.md#шаг-55--ключ-для-ии-анализа-обязательно-для-run-llm-analysis).
> Перед боевым использованием проверьте на тестовом кабинете с небольшим бюджетом.

## Быстрый старт (локальная разработка)

```bash
git clone https://github.com/vkrn-work/ppc-optimaizer
cd ppc-optimaizer
docker-compose up -d

# Фронтенд: http://localhost:3000
# API docs: http://localhost:8000/docs
```

Чтобы протестировать ИИ-анализ локально — добавьте хотя бы один ключ в `.env`
(`GEMINI_API_KEY` или `GROQ_API_KEY` — бесплатно, без карты). Подробнее — в
[docs/PROJECT_DOCUMENTATION.md](docs/PROJECT_DOCUMENTATION.md), раздел «Локальная разработка».
